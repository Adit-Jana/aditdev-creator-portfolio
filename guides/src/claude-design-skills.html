01–02Interfaces that look designed

01anthropics/skills · frontend-design

Frontend design

Anthropic's skill for giving UI a clear visual direction: typography, palette and layout choices that don't read as a template.

Use it for: landing pages, dashboards, portfolios. Tell it the mood ("calm, Apple-like, one accent colour") and it commits to it.

/plugin install frontend-design@claude-plugins-official
02nextlevelbuilder/ui-ux-pro-max-skill · ~152k stars

UI UX Pro Max

A large design-intelligence skill: styles, colour palettes, font pairings, UX rules and chart types it searches before it builds, across many front-end stacks.

Use it for: when you have no designer and need sound defaults fast.

/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill

03–05Video and motion graphics, from code

These let Claude write animations as code you can edit, re-render and version in git. Great for explainer reels, product demos and animated captions.

03remotion-dev/skills · official Remotion skills

Remotion

Remotion makes videos with React. The official skills teach Claude Remotion's rules: timing with frames, captions, audio and video, maps, and rendering.

Use it for: data-driven or templated videos, such as 20 variations of one reel with different text.

npx skills add remotion-dev/skills
04heygen-com/hyperframes · ~87k stars

HyperFrames

HeyGen's open-source framework for video written as HTML and CSS. Claude composes scenes, and the CLI previews and renders them to MP4.

Use it for: motion graphics and kinetic text when you already think in web design.

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes
05greensock/gsap-skills · official GSAP skills

GSAP

Official skills from the GSAP team so Claude writes correct timelines, scroll-triggered animation and easing instead of guessing the API.

Use it for: scroll animations on websites and animated scenes inside HyperFrames.

npx skills add https://github.com/greensock/gsap-skills
Which video tool?Already use React → Remotion. Prefer plain HTML and CSS → HyperFrames. Animating a website → GSAP.

06–09Posters, art, themes and GIFs

All four are in Anthropic's skills repo. Install once:

/plugin marketplace add anthropics/skills
/plugin install example-skills@anthropic-agent-skills
06anthropics/skills · canvas-design

Canvas design

Creates finished visual pieces as PNG or PDF (posters, covers, art) by first writing a short design philosophy, then executing it.

Use it for: event posters, thumbnails, one-off social graphics.

07anthropics/skills · algorithmic-art

Algorithmic art

Generative art in p5.js with seeded randomness, plus sliders to explore variations.

Use it for: unique backgrounds, brand textures, loops for reels.

08anthropics/skills · theme-factory

Theme factory

Ten ready themes (colours and fonts) Claude can apply to slides, docs, reports and landing pages, or a new theme made on the spot.

Use it for: making everything you produce look like one brand.

09anthropics/skills · slack-gif-creator

Slack GIF creator

Builds small animated GIFs that meet Slack's size limits, with validation tools and animation ideas.

Use it for: reaction GIFs, tiny product teasers, team celebrations.

→Prompts that get good results

A landing page that doesn't look AI-made

Use the frontend-design skill. Build a one-page site for [product].
Mood: calm and premium, like an Apple product page. One accent colour.
Big type, lots of white space, one idea per section. Works in light and dark
mode and at phone width. No purple gradients, no emoji, no stock icons.
Before coding, tell me the palette, fonts and layout in 5 lines.

A 20-second animated explainer

Use HyperFrames (or Remotion). Make a 1080x1920, 20-second explainer:
"How a context window works". Scenes: (1) a chat filling a whiteboard,
(2) the whiteboard gets full, (3) the oldest messages slide off.
White background, navy text, one yellow highlight. Text on screen for at
least 2 seconds per line. Show me a storyboard of 3 frames per scene first.

A poster in one shot

Use canvas-design. A 4:5 poster for a workshop called "Ship with Claude".
Swiss style, strong grid, one bold headline, date and place small at the
bottom. Export PNG at 1080x1350.
