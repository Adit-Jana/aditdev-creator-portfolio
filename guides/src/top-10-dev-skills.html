00First, what is a skill?

A skill is a folder with a SKILL.md file: instructions, and sometimes scripts, that Claude loads only when the task needs them. A plugin is a package of skills, agents and hooks you install in one go.

ToRun inside Claude Code
Add a plugin marketplace/plugin marketplace add owner/repo
Install a plugin/plugin install name@marketplace
Browse what you have/plugin
Call a skill by hand/skill-name

Skills 1–4 come from one plugin, Superpowers by Jesse Vincent (obra/superpowers, about 322k stars on GitHub). Skills 5–7 are official Anthropic plugins. Skills 8–10 are from Anthropic's public skills repo (anthropics/skills, about 198k stars).

01–04The Superpowers core

These four change how Claude works, not just what it knows. Together they stop the two most common failures: building the wrong thing, and saying "done" when it isn't.

01obra/superpowers · brainstorming, writing-plans, executing-plans

Brainstorm, then write a plan

Before any code, Claude asks questions until the goal is clear, writes a step-by-step plan into a file, then works through it task by task.

Use it for: any feature bigger than one file. You review a plan in two minutes instead of untangling 400 wrong lines.

02obra/superpowers · test-driven-development

Test-driven development

Write a failing test, watch it fail, write the smallest code that passes, then clean up. The skill makes Claude follow that order every time.

Use it for: business logic and bug fixes. A failing test is the clearest spec you can give an AI.

03obra/superpowers · systematic-debugging

Systematic debugging

Triggers on any bug or failing test. Claude has to find the root cause (reproduce, trace, form one hypothesis, test it) before it proposes a fix.

Use it for: the bug Claude already "fixed" three times. It ends the guess-and-patch loop.

04obra/superpowers · verification-before-completion

Verification before completion

Before Claude says something is fixed or passing, it must run the check and show you the output. Evidence before claims.

Use it for: everything. This one skill removes most "it said done but nothing works" moments.

05–07Official Anthropic plugins

05claude-plugins-official · feature-dev

Feature dev

A structured workflow for a new feature with specialist agents: one explores the codebase, one designs the architecture, one reviews quality at the end.

Use it for: features in a codebase you don't know well. The explorer agent finds the patterns you should follow.

06claude-plugins-official · code-review

Code review

Reviews a pull request with several specialised agents and scores each finding by confidence, so you see real problems, not a wall of nits.

Use it for: a second pair of eyes before you ask a human to review. Pair it with pr-review-toolkit for test-coverage and error-handling checks.

07claude-plugins-official · security-guidance

Security guidance

Warns on known dangerous patterns as Claude writes code (unsafe deserialisation, raw HTML injection and more), then reviews the diff when Claude finishes and sends serious findings back to be fixed.

Use it for: any code that touches user input, files or auth.

08–10From Anthropic's skills repo

08anthropics/skills · webapp-testing

Webapp testing

Lets Claude drive your local web app with Playwright: click through flows, take screenshots, read browser logs.

Use it for: checking a UI change actually works in a browser, not just that it compiles.

09anthropics/skills · mcp-builder

MCP builder

A guide for building good MCP servers, so Claude (and other AI tools) can use your internal APIs through well-designed tools.

Use it for: connecting Claude to your company's service, database or admin panel.

10anthropics/skills · skill-creator

Skill creator

Helps you write, test and improve your own skills. The best skill is the one that encodes how your team works.

Use it for: turning your most repeated prompt into a /command the whole team can use.

→A day with these skills

  1. Morning, new ticket: "Let's brainstorm this feature" → Claude asks questions → writes plan.md.
  2. Build: "Execute the plan with TDD" → failing test, code, passing test, per step.
  3. Something breaks: systematic-debugging kicks in → root cause first, then one fix.
  4. Before you commit: verification runs the suite and shows output; security-guidance reviews the diff.
  5. Open the PR: /code-review → fix the high-confidence findings → ask a human.

Master prompt: pick skills for your repo

Look at this repository (language, framework, test setup, CI) and my last
20 commits. Then:
1. Tell me which of these would help most here and why, best first:
   superpowers, feature-dev, code-review, security-guidance, webapp-testing,
   mcp-builder, skill-creator, and the language-server plugin for my stack.
2. Give me the exact /plugin commands to install your top 5.
3. Find the task I repeat most in my commits and draft a SKILL.md for it in
   .claude/skills/. Show it to me before saving.
